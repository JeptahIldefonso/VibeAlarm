# Icon Attribution

## Status: SOURCES UNCONFIRMED — review before public distribution

The vector icons in this folder were supplied by the app author as `.svg` files. **None of the
original files carry source, author, or license metadata** (no generator comments naming an
icon set, no license URLs, no copyright lines), so the exact license terms of each icon are
not yet established.

`checkbox.svg` arrived as an Adobe Illustrator export with Spanish layer naming
(`Capa_1`), which is characteristic of Flaticon/Freepik-style stock icon exports — **those
services have specific attribution and redistribution terms that must be checked** if that is
where these came from.
